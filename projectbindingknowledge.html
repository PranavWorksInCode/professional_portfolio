Binding Knowledge

Comprehensive multi-role EdTech & educational management platform (formerly Teacher's Hub)

Overview

Binding Knowledge (formerly Teacher's Hub) is a comprehensive, multi-role educational management platform engineered to streamline communication, scheduling, and academic tracking between administrators, educators, students, and parents. The platform prioritizes a modern, responsive user interface with native dark-mode support and secure role-based access control.

Key Features & Capabilities

1. Robust Multi-Role Architecture

Implemented a secure authentication system supporting four distinct user roles, each with a tailored dashboard and specific database access privileges enforced by Supabase Row Level Security (RLS):

  • Administrators: Global oversight, user provisioning, and system configuration.
  • Teachers: Course management, grading, and student communication.
  • Students: Academic tracking, resource access, and assignment submission.
  • Parents: Multi-child academic monitoring and teacher communication.

2. Advanced Administrator Controls

Equipped with a Global Batch Manager interface for admins to assign students to specific subject batches taught by designated teachers, preventing scheduling conflicts. Features an automated PostgreSQL sequence generator for unique 7-digit Roll IDs, instant user provisioning forms, and searchable datalists for fast student lookup when linking parent accounts.

3. Academic & Assignment Management

Teachers can create assignments, set due dates, grade submissions, and provide written feedback that instantly syncs across Student and Parent dashboards. Integrated jspdf and jspdf-autotable to export stylized PDF reports of student grades and attendance with a single click.

4. Comprehensive Parent Portal

Designed a many-to-many database schema allowing a single parent account to securely link with multiple children. Parents can monitor overall attendance rates, pending tasks, and recent grades for all their children on a unified, holistic dashboard.

5. Direct Messaging & Leave Request Workflow

Built real-time cross-role direct messaging with nested cohort filters for admin announcements. Integrated an interactive leave request system allowing students to request absences and teachers to approve or reject them with real-time attendance sync.

Technical Highlights

Built on Next.js 14, React, TypeScript, and Supabase (PostgreSQL). Leverages Row Level Security (RLS) policies to enforce granular database protection, optimistic UI state updates for zero-latency interactions, glassmorphism design tokens, and dynamic dark mode color palettes.
