PayPulse AI

Enterprise FinTech Fraud Analytics & AI Copilot Platform

Overview

PayPulse AI is a high-throughput FinTech fraud analytics and real-time threat intelligence platform engineered specifically for the Indian payment ecosystem (UPI, Credit Cards, NetBanking, and BNPL). It evaluates 15,000+ simulated transactions/second with sub-15ms latency, featuring an interactive Razorpay/UPI payment sandbox, sliding-window velocity rule engine, and an embedded LLM-powered Financial Copilot.

Key Features & Capabilities

1. 📡 Live Fraud Radar & Streaming Engine

Real-time simulated ingestion of Indian market payment streams (Swiggy, Zerodha, CRED, Flipkart, Zomato, Meesho). Evaluates threat vectors including TOR exit node detection, jailbroken/rooted device fingerprinting, proxy IP detection, and ML risk scoring (0-100%).

2. 🤖 Conversational AI Financial Copilot

Natural language RAG assistant empowering compliance officers and fraud investigators to query live telemetry data, run automated risk analyses, and trigger 1-click audit summary prompts for rapid incident investigation.

3. 💳 Razorpay & UPI Payment Gateway Sandbox

Interactive checkout simulator supporting GPay, PhonePe, Paytm UPI, HDFC Regalia Cards, and Simpl BNPL. Includes live threat vector injection toggles to simulate proxy IPs, high-velocity retry spikes, or night-time high-value transfers.

Technical Highlights

Built using React, Vite, Tailwind CSS, and GenAI LLM RAG pipelines. Designed with sub-15ms latency evaluation, sliding-window velocity rule engines, and interactive sandbox environments.
